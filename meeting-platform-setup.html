Set Up the Meeting App Without Hiding Camera Problems

A guide to input selection, preview checks, platform effects, bandwidth, and repeatable video-call setup.

Guide by Mara Ellison · room-first, no product-testing claim

Choose the intended input explicitly

Meeting software can remember an older webcam, a virtual camera, or a dock input after equipment changes. Select the device by name before a call and confirm the preview corresponds to the physical lens in front of you. Treat this as a delivery-path check, not proof from a manufacturer preview. The useful output is a known application, permission, effect, and fallback path that preserves a readable person when a meeting begins.
